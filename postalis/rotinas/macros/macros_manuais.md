# Macros Manuais (Ctrl + F8)

Estas macros podem ser executadas manualmente pelo usuário para validação, correção ou reprocessamento pontual.

---

## AplicarFormulasPendencias
Módulo mantido por compatibilidade com o fluxo principal.

Na arquitetura atual não aplica fórmulas nem altera estrutura
de tabelas. Atua apenas como etapa intermediária chamada pelo
botão principal para manter organização do fluxo VBA.

## AplicarLayoutPadraoTabelas
Padroniza layout visual das tabelas do sistema.

## AplicarLayoutPadraoTabelas_Forcar
Força reaplicação de layout mesmo se já aplicado.

## Manual_Backfill_Pendentes_0202
Executa backfill somente para registros pendentes no ciclo.

## Manual_Backfill_Rapido_0202
Executa backfill simplificado para ajustes rápidos.

## Manual_IncluirIDs_PeloHistorico_0202
Inclui IDs a partir do Histórico Bitrix (baseline 01/02/2026).

## Manual_IncluirNovosIDs_PeloFinal
Inclui novos IDs detectados na extração atual.

## PQ_BackgroundOff
Desativa execução em background das consultas Power Query.

## Rotina_Sincronizar_E_Recalcular
Sincroniza base e recalcula estruturas auxiliares.

## Sincronizar_AteX_RegistrosContatos
Sincroniza ciclo até o limite definido.

## Sincronizar_RegistrosContatos_Manual
Sincroniza registros manuais com base oficial.
