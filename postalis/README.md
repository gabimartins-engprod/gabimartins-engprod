# Rotina_Dados — Postalis

Este repositório concentra a documentação e a organização lógica de uma rotina administrativa
voltada ao acompanhamento, tratamento e monitoramento de dados extraídos do Bitrix.

O projeto não contém dados reais e tem como foco a **padronização, automação e melhoria contínua**
dos processos envolvidos.

---

## Objetivo do projeto

- Documentar a arquitetura da rotina de dados
- Organizar códigos de automação (Power Query e VBA)
- Facilitar manutenção, auditoria e evolução do processo
- Servir como base estruturada para futuras melhorias e indicadores
